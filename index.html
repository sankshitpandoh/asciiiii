リードミー □×
FileEditSearchHelp

  1. Load the script once per page

    <script type="module"
  src="https://cdn.jsdelivr.net/gh/sankshitpandoh/asciiiii@main/dist/ascii-art.min.js">
</script>

    Or install it from GitHub and import it in your bundle:

    npm i github:sankshitpandoh/asciiiii

import 'asciiiii';

    36 kB gzipped with every piece. Only need conversion? dist/ascii-art.core.min.js is 11 kB.

  2. Place a tag

    <ascii-art piece="donut"></ascii-art>

<ascii-art src="/me.jpg" cols="90" color animate="flicker"></ascii-art>
<ascii-art src="/clip.mp4" cols="90" fps="12"></ascii-art>

<ascii-art animate="wave">
  <script type="application/json">{ pasted from EXPORT.DLL }</script>
</ascii-art>

    Pictures and clips convert in the visitor's browser. Pasted art needs no media file at all. In React, Vue, Svelte or Astro, import the script once on the client and use the same tag; pieces render nothing on the server and start on mount.

  3. Style it like text

    ascii-art {
  --ascii-font-size: 8px;
  --ascii-fg: #ff71ce;
  --ascii-bg: transparent;
}

Attributes

AttributeWhat it does
pieceA built-in piece by name, like donut. options takes JSON overrides.
srcAn image, GIF or video URL to convert in the browser.
cols, rowsCharacters per row (default 80), and a row limit.
charsetstandard, detailed, blocks, minimal, binary, dots, slashes, letters, or your own ramp.
color, mono, invertKeep colour, draw in one ink, or prepare for light backgrounds.
animate, fpsPhoto effects (flicker, wave, scan, typewriter) and frame rate.
font-size, fg, bgShortcuts for the CSS variables.
altWhat screen readers announce.
motionalways animates even with reduced motion on; off always shows a still frame.

Performance and accessibility

  • Animations stop while off-screen, so a page full of pieces stays cheap.
  • With prefers-reduced-motion on, pieces show their first frame and effects stay still.
  • Each element is announced as one image with its alt text, not as hundreds of characters.
  • No dependencies, no network calls except the media you point it at.
