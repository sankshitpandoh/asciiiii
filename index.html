How embedding works

  1. Load the script once per page

    <script type="module"
  src="https://cdn.jsdelivr.net/gh/sankshitpandoh/asciiiii@main/dist/ascii-art.min.js">
</script>

    About 100 kB with every piece, or 30 kB for the core build without them.

  2. Place a tag

    <ascii-art piece="donut"></ascii-art>

<ascii-art src="/me.jpg" cols="90" color animate="flicker"></ascii-art>
<ascii-art src="/clip.mp4" cols="90" fps="12"></ascii-art>

<ascii-art animate="wave">
  <script type="application/json">{ pasted from the Embed tab }</script>
</ascii-art>

    Pictures and clips convert in the visitor's browser. Pasted art needs no media file at all.

  3. Style it like text

    ascii-art {
  --ascii-font-size: 8px;
  --ascii-fg: #1c261f;
  --ascii-bg: transparent;
}

    Animations pause off-screen and respect prefers-reduced-motion. React, Vue, Svelte and Astro can use the same tag; there is also a JavaScript API, import { imageToAscii } from 'asciiiii'.
